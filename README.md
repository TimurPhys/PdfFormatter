# Label Text Scaler & PDF Optimizer

**Label Text Scaler** — это утилита для автоматической предпечатной подготовки логистических бирок. Программа решает проблему мелкого, нечитаемого шрифта в клиентских PDF-файлах, делая их пригодными для качественной печати на термопринтерах.

## 📌 Проблема

Часто клиенты присылают бирки, в которых текст настолько мелкий, что стандартные принтеры (особенно термопринтеры с низким DPI) превращают его в нечитаемые пятна. Это приводит к проблемам при сканировании штрихкодов и чтении адресов доставки.

## ✨ Решение

Программа автоматизирует процесс «пересборки» документа, который вручную занял бы часы:

1.  **PDF to DOCX:** Конвертирует исходный файл в редактируемый формат.
2.  **Smart Font Scaling:** Находит все текстовые объекты и пропорционально увеличивает размер шрифта.
3.  **Auto-Resizing:** Подгоняет размеры документа под нужный формат бумаги (например, 10x15 см, 58x40 мм и др.).
4.  **PDF Export:** Возвращает обработанный файл в формат PDF, готовый к печати.

## 🚀 Основные функции

- ✅ **Автоматическое увеличение текста:** Больше не нужно вручную перебивать данные.
- ✅ **Коррекция размеров:** Адаптация под любой размер этикет-ленты.
- ✅ **Сохранение структуры:** Программа старается сохранить расположение элементов, увеличивая только читаемость.
- ✅ **Пакетная обработка:** Обработка многостраничных PDF-файлов за один раз.

## 🛠 Технологии

- **Python 3.x**
- **Библиотеки:** `pdf2docx` (конвертация), `python-docx` (манипуляции с текстом), `docx2pdf` (финальный экспорт).

## ⚙️ Инструкция по установке

1. Клонируйте репозиторий:

   ```bash
   git clone [https://github.com/ваш-профиль/label-text-scaler.git](https://github.com/ваш-профиль/label-text-scaler.git)
   ```

2. Укажите пароль для входа (стандратный указан в коде)

3. Если захотите поменять пароль, то его придется захешировать и указать новый хэш в коде (файл protection.py)
